# 📚 Library Management System

A console-based **Library Management System** developed using **Java and Object-Oriented Programming (OOP)** principles.

This project is designed to simulate the basic operations of a real-world library, such as managing books, managing users, issuing books, and returning books.

---

## 🚀 Features

- 📖 Add new books
- 🔍 Search books
- 📋 View all available books
- 🗑️ Remove books
- 👤 Manage library members
- 📤 Issue books
- 📥 Return books
- 🔄 Track book availability
- ⚠️ Handle invalid operations
- 🧩 Object-Oriented design

## 🧠 OOP Concepts Used

This project was built to practice and demonstrate the core concepts of Java OOP.

### 1. Encapsulation

Data and related methods are grouped inside classes while controlling access to the internal state.

### 2. Inheritance

Common properties and behaviors can be reused through parent-child class relationships.

### 3. Polymorphism

The same method or reference can work with different object types.

### 4. Abstraction

Complex implementation details are hidden behind simple interfaces or abstract classes.

---

🔄 How It Works

The system is organized around different objects such as Books, Members, and Library.

The LibraryService is responsible for handling the main library operations, while the model classes represent the data and behavior of the system.

For example:

User → LibraryService → Library → Book / Member

This structure helps demonstrate how real-world applications can be divided into separate responsibilities instead of placing all the logic inside a single class.
